# Giga Klibadze

## Name

LeverX first lecture project

## Description

I built a page with plain HTML/CSS which accepts next criterias:

- Responsive header (mobile + desktop)
- Basic and Advanced search optionis
- Employee list displayed in Grid and a List views
- Not found page is implemented where there are no users
- Burger menu with interactive opening/closing behavior

## Features

- Page header
- Search and filtering section
- Main section with employee list
- Separate NOT FOUND page

## Workflow

I build the page with mobile first approach, then implemented some necessary features, since it's a lot more comfortable flow.

## Technologies

- Plain HTML
- Plain CSS
- No JS
